##Real time chat application

backend (Node.js + Socket.IO):

Real-time messaging using WebSocket
Simple user authentication with JWT
In-memory message storage
Express server for API endpoints
Frontend (React + Tailwind CSS):

Beautiful, responsive UI
Real-time message updates
User authentication (login/register)
Message history
Auto-scroll to latest messages
Loading states and error handling
Lucide icons for better UX
Features:

User registration and login
Persistent authentication using localStorage
Real-time message delivery
Message timestamps
User-friendly interface
Responsive design for all screen sizes
To use the application:

The Node.js server will start on port 3000
The React development server will start on port 5173
Register a new account or login
Start chatting!
The UI is modern and professional, with:

Clean layout and spacing
Clear message bubbles
Visual distinction between sent and received messages
Smooth animations and transitions
Proper error handling and loading states
